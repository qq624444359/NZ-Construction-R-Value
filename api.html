H1 R-value API and MCP server

The calculator’s model, without the page: construction R-values for walls, roofs and floors to H1/AS1 6th edition, and the Calculation Method PASS / FAIL. Ask an AI assistant whether a design meets H1, or check it from Revit while you draw.

It runs the same code as the calculator, so the numbers match the website. It is free, needs no key, and does not store what you send.

MCP server

Add this address to any AI assistant that takes a remote MCP server (in Claude, as a custom connector):

https://rvalue.ezbuild.co.nz/api/mcp

For clients configured with a JSON file:

{
  "mcpServers": {
    "ezbuild-rvalue": { "url": "https://rvalue.ezbuild.co.nz/api/mcp" }
  }
}
ToolWhat it does
list_construction_typesEvery wall, roof and floor type — timber frame, block wall, truss and skillion roofs, suspended timber floor, slab-on-ground — with its options.
describe_constructionThe layers of one type, outside to inside: material choices with their R-values, framing, insulation, or the slab inputs.
calculate_constructionThe construction R-value, each layer and each bridged path (NZS 4214 as modified by 2.1.3.2; slab-on-ground by Appendix E).
check_h1PASS / FAIL by the Calculation Method from each element’s area and R-value, worked the way the BRANZ H1/AS1 tool works it.

Then ask in plain words, for example: “A 90 × 45 @ 600 wall with brick veneer and R2.8 batts, a truss roof with two layers of R3.6, a 100 m² raft slab with 42 m perimeter, 30 m² of R0.46 windows, Auckland — does it meet H1?”

Revit (pyRevit)

A pyRevit button that sums the areas in your model, sends them with each type’s R-value to check_h1, and shows PASS / FAIL and the heat-loss table.

  1. Install pyRevit. Download EZbuild.extension.zip and unzip it into a folder of your own, e.g. C:\pyRevit-extensions, so that the folder holds EZbuild.extension.
  2. In Revit: pyRevit tab → Settings → Custom Extension Directories → add that folder → Save Settings and Reload. An EZbuild tab appears with the H1 Check button.
  3. Add two parameters to the wall, roof, floor, ceiling, window and door types you want counted: H1 Element (text: roof, wall, slab, floor, skylight, glazing or door) and H1 R-value (number — from the calculator). Optional: H1 Heated and, on roofs, H1 Ceiling Perimeter (yes/no).
  4. Add H1 Climate Zone (integer, 1–6) to Project Information, or pick it when asked.
Walls, roofs, floors and ceilings use Revit’s computed area; windows and doors use width × height. H1/AS1 2.1.2.10 asks for finished internal-face areas, so check the areas against that before you rely on the result. The script has not yet been tried in every Revit version — tell us if it doesn’t run in yours.

HTTP API

JSON in, JSON out, CORS open. Base address https://rvalue.ezbuild.co.nz/api/v1.

RequestReturns
GET /typesConstruction types and options
GET /describe?element=wall&kind=blockThe layers of one type and what each accepts (options=cav,-strap to switch options)
POST /constructionR-value of one construction
POST /h1-checkPASS / FAIL, heat loss proposed and reference

A wall

curl -X POST https://rvalue.ezbuild.co.nz/api/v1/construction \
  -H "Content-Type: application/json" \
  -d '{"element":"wall","kind":"frame","name":"W1 Brick veneer",
       "layers":{"clad":"brick-veneer-70-mm",
                 "fr":{"depth_mm":90,"centres_mm":600,"insulation_r":2.8,"insulation_mm":90},
                 "lin":"plasterboard-10-mm"}}'

Layers you leave out keep the calculator’s defaults. A material can be given by id or by an unambiguous part of its name, or as {"r": 0.05} for your own R-value.

A slab-on-ground floor

{"element":"floor","kind":"slab",
 "slab":{"area_m2":100,"perimeter_m":42.04,"floor":"raft","wall_thickness_mm":90,
         "parts":[{"length_m":17.15,"wall":"masonry"}]}}

The H1 check

curl -X POST https://rvalue.ezbuild.co.nz/api/v1/h1-check \
  -H "Content-Type: application/json" \
  -d '{"climate_zone":1,"elements":[
        {"type":"roof","area_m2":100.8,"r_value":7.45},
        {"type":"wall","area_m2":243.6,"r_value":1.60},
        {"type":"glazing","area_m2":70.5,"r_value":0.46},
        {"type":"door","area_m2":2.4,"r_value":0.18},
        {"type":"slab","area_m2":100,"r_value":1.27}]}'

Element types: roof, wall, slab, floor (suspended and other floors), skylight, glazing (windows and glazed doors), door (opaque). Add "heated": true for an element with heating in it, and "ceiling_perimeter": true for a roof’s ceiling perimeter strip.

What it does not do

  • Material, air-gap and surface values are provisional defaults. Confirm each against NZS 4214 and the manufacturer before a figure goes into a consent.
  • The H1 check is the Calculation Method only. The BRANZ H1/AS1 calculation tool’s own result is the one for the building consent authority.
  • It is not a modelling-method (H1/VM1) tool, and it does not read drawings or Revit materials’ thermal properties.
