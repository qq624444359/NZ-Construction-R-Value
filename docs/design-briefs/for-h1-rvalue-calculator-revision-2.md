## 一、层列表必须在框架层分叉成两列（结构性，最重要）

现在的层列表是一条从上到下的单列，其中木结构那一层写着
`R3.60 · effective R3.40 after 12% framing`。

**标准不是这么算的。** NZS 4214 clause 5.7.1 的 isothermal planes 方法在框架穿透的那
一段里有**两条并联热流路径**——一条穿过木头，一条穿过旁边的保温——各自算完整的层
叠电阻，再按面积占比做**电导加权**，最后才和其他层串联：

```
1/Rb = f₁/R₁ + f₂/R₂        每条路径的面积占比 f 除以该路径的电阻
Rb   = 1 / (1/Rb)
RT   = Rsi + …外层… + Rb + …内层… + Rse
```

把两条路径先合成一个「effective R」再往下走，是另一种算法，结果会偏高。

### 要出的布局

层列表在进入桥接段时**从整宽单列分叉成并排两列**，出了桥接段再合回单列：

```
┌───────────────────────────────────────────────────────────────┐
│ ·  Outside surface                                       R—   │  ← 单列，整宽
├───────────────────────────────────────────────────────────────┤
│ ①  Roofing            [ Corrugate ▾ ]                    R—   │
├───────────────────────────────────────────────────────────────┤
│ ②  Underlay           [ Self-supporting ▾ ]              R—   │
├───────────────────────────────────────────────────────────────┤
│ ╔═══ BRIDGED PORTION ═══════════════════════════════════════╗ │  ← 分叉开始
│ ║  Timber framing  12.0%   │  Insulation        88.0%      ║ │  ← 两列表头
│ ║  ─────────────────────── │ ──────────────────────────    ║ │
│ ║  ③ Truss bottom chord    │  ③ Ceiling insulation         ║ │
│ ║     90 mm timber   R—    │     R3.60 · 175 mm    R3.60   ║ │
│ ║  ─────────────────────── │ ──────────────────────────    ║ │
│ ║  Path resistance   R—    │  Path resistance      R3.60   ║ │
│ ╠═══════════════════════════════════════════════════════════╣ │
│ ║  1/Rb = 0.120/R— + 0.880/R3.60                            ║ │  ← 合成行
│ ║  Combined                                          R—     ║ │
│ ╚═══════════════════════════════════════════════════════════╝ │
├───────────────────────────────────────────────────────────────┤
│ ⑧  Ceiling lining     [ 13 mm plasterboard ▾ ]           R—   │  ← 合回单列
├───────────────────────────────────────────────────────────────┤
│ ·  Inside surface                                        R—   │
└───────────────────────────────────────────────────────────────┘
```

设计要点：

- 桥接段用一个**明显的容器**框住：`--surface-2` 底 + 1px `--border-strong` 边框 +
  左上角一枚 `BRIDGED PORTION` 的 kicker 小标签（品牌色、10px、全大写）
- 两列表头显示**路径名 + 面积占比**，占比用等宽字体
- 两列之间一道 1px `--hairline` 竖分隔
- 每列底部一行 `Path resistance`，是该路径各层之和
- 容器底部**跨两列**一行合成：显示 Eq.5 的算式和结果 `Combined R…`
- 合成行的底色比容器再深一档（`--surface-3`），表示它是这一段的输出

**屋顶会出现两个桥接段**：下弦 + 保温是一段，ceiling batten 是另一段（battens 与下弦
垂直交叉）。所以容器要能出现不止一次——两个容器之间可以夹单列的层。

具体怎么分组由 H1/AS1 **2.1.3.2** 的规则决定（它整条替换了 NZS 4214 的 5.7.1 a)），
后端会算好告诉前端。稿子只需要表达「分叉可以发生、且可以发生多次」。

## 二、3D 换成 gable roof 剖切，不要平铺层叠

现在的爆炸图是一摞水平薄板。它有个致命缺陷：**画不出檐口。**

而檐口正是 R 值真正失效的地方——heel height 不够时保温在那一圈被压扁。第一轮已经把
这个交互写进去了，但平铺的层叠图没法把它画出来。

### 要出的图

一个**山墙屋顶的轴测剖切**：屋面沿脊线剖开，露出内部构造。参考实物做法：

- 左半边保留完整屋面（能看到 corrugate/trapezoidal 的波形），右半边剖开
- 剖面里看得到：桁架（下弦、腹杆）、保温层、ceiling batten、天花板
- **檐口那一段是重点**：要能看清下弦怎么落到墙顶、heel 的高度、保温在檐口收到多薄
- 保温层用半透明填充，能透出后面的桁架 —— 让「保温被框架打断」这件事可见
- 各层用**引出线**连到左栏对应的层卡（这是从同类产品学来的做法：3D 上的部位和表单
  字段之间画细引线，一眼看清哪个控件对应哪块料）
- 左栏选中某层 → 3D 里该层高亮、其余降到 40% 不透明；反之点 3D 也能选中左栏

### 几何要由输入驱动，这是它存在的理由

- 改 **heel height** → 檐口那块**真的变高变矮**
- 改 **batten spacing** → 阵列间距真的变
- 改 **insulation thickness** → 保温层真的变厚，超过 heel 时檐口真的被压扁
- 改 **roofing profile** → 波形真的换

做不到随输入变化的部分，宁可不画。

### 视角

**三个预设视角**，不做自由旋转：`Eaves detail`（默认，看檐口）· `Ridge` ·
`Full section`。切换用右上角的 chip 组，和第一轮那三个视图 chip 合并成一组。

右下角一枚放大镜按钮，点开把檐口那一段放大到整个面板 —— 因为那里是判定发生的地方。

## 三、所有编造的层 R 值改成占位

现在稿子上每层都有具体数字（`R0.04` `R0.46` `R0.14` …）。**这些数字没有来源，是生成
出来的。**真实值在 NZS 4214 附录 E，我们还没有取得在产品中使用它的授权。

所以这一轮：

- **每一层的 R 值一律显示 `—`**（em dash，等宽字体，`--text-3` 色）
- **右上角的总 R 值也显示 `—`**，进度条置灰、指针不出现
- **唯一显示真实数字的是用户自己输入的保温 R 值**（⑥ 那一层和 batten 里的附加保温），
  以及从产品面板选中的厂商声明值
- 面积占比（`12.0% / 88.0%`）保留真实数字 —— 那是几何算出来的，不来自标准的表

顶部加一条 `--review-soft` 横幅：

```
Layer R-values are not shown yet. Surface, air-space and material values come
from NZS 4214 Appendix E, which we are not yet licensed to use in this tool.
The method is implemented; the tables are pending.
```

**这不是临时妥协的丑陋状态，要把它设计好。**一个诚实地说「这里还没有数据」的界面，
比一个填满了看起来很专业的假数字的界面强得多 —— 后者会被人拿去报建。

## 四、Framing fraction：38% 和实算值要并排显示

第一轮已经要求在结论块下方显示 framing fraction。这一轮把它做成一个**独立的小面板**，
因为它是整个计算里最容易被做错、也最值钱的一个输入。

H1/AS1 **2.1.3.1 a) i)** 规定：框架墙的 framing fraction **不得低于 38%**，除非能
**证明**更低的值适用于该建筑。

而按 NZS 4214 附录 F1 的算法，一面 600 中距、47mm 框架、2.4m 高的标准墙板算出来只有
约 **15%**。差距巨大——但那是一块「净墙板」，不含转角、交接、门窗洞口、过梁处的额外
框架，所以它本身**不构成 2.1.3.1 a) i) 要求的那个证明**。

### 要出的面板

```
FRAMING FRACTION

  ● 38.0%   H1/AS1 default          ← 选中态，品牌色
  ○ 15.1%   Calculated from geometry

  [ Enter wall geometry → ]

  ⚠ A clear-panel figure is not on its own the demonstration that
    Paragraph 2.1.3.1 a) i) asks for. It excludes the extra framing at
    corners, junctions, lintels and around openings.
```

两个值**并排列出**，用户明确选一个。选 `Calculated` 时：

- 展开几何输入：`Stud width` · `Stud spacing` · `Panel height` · `Horizontal members`
- 上方警告转成 `--review` 实心提示条，不能折叠
- 右上角结论块的 R 值旁出现一枚 `Non-default framing` 的 `--review` 徽章

并且在两个值旁边各显示**它导致的 R 值**，让取舍可见：

```
  ● 38.0%  →  R—        H1/AS1 default
  ○ 15.1%  →  R—        Calculated · needs justification
```

（R 值现在是 `—`，见第三节。）

## 六、不要做的事

1. **不要把两条并联路径合成一个数字再往下走。** 那不是 5.7.1。
2. **不要给任何层填具体 R 值**，除非它是用户输入的或厂商声明的。
3. **不要做自由旋转的 3D。** 三个预设视角，几何随输入变化，比能转重要得多。
4. **不要把 38% 做成默认值就藏起来。** 它和实算值必须并排、可比较。
5. **不要用红色表示 framing fraction 选了实算值。** 那是合法路径，只是需要举证——
   用 `--review` 不是 `--fail`。
