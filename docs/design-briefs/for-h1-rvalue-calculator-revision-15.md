# 粘贴给 Claude Design 的说明 —— R-value Configurator 第十五轮

前面所有轮次的内容保留。全站文案英文，下面给出的 copy 逐字使用。

## 一、交互：点保温层，产品表升上来

### 触发

左栏 `THROUGH THE INSULATION` 列表里的任意一层被**点击**时进入"选产品"状态：
`Ceiling insulation`、`Over the framing`、`Between the battens`、`Roof perimeter`
都算。点的是哪一层，就是给哪一层选产品。

### 右栏的变化

```
平时                                  选产品状态
┌─────────────────────┐              ┌─────────────────────┐
│ Section · eaves     │              │ ▭ 剖面图缩成一条     │ ← 高 120px，仍然实时
│ （剖面图 360px）     │              ├─────────────────────┤
│                     │    ───▶      │ Ceiling insulation  │ ← 标题写正在选的层
├─────────────────────┤              │ Choose a product    │
│ Insulation          │              │                     │
│ （产品表，矮）       │              │ （产品表拉高，占满   │
│                     │              │   剩下的整个右栏）   │
└─────────────────────┘              │                     │
                                     │            [ Done ] │
                                     └─────────────────────┘
```

- **剖面图不消失**，缩成顶部一条 120 px 高的缩略图（同一个 `eavesSection()`，只是容器变矮，
  SVG 等比缩放、居中裁到保温和檐口那一段）。换产品时它实时重画，用户能直接看到保温
  变厚变薄
- **产品表升到缩略图下面，高度拉满**：`height: calc(100vh - 88px - 120px - 间距)`，
  表内滚动
- 产品表标题换成正在选的那一层：`Ceiling insulation` + 副标题 `Choose a product`
- 左栏被点的那一行保持 `--brand` 高亮边框，其他行降到 60% 不透明，视线集中

### 表里的内容

- **当前选中的产品**置顶显示一行 `Current`，下面才是完整列表
- 每行：`R2.6 · 110 mm` / `432 wide` / 状态 chip（沿用第十轮：`Fills a 90 mm chord` 等）
- 放不下的产品（比 `Depth at the wall line` 更厚，会被压）右侧加一枚 `--review` 小 chip
  `Squashed at the eaves`，**不禁选**，只提示
- **悬停某一行 = 预览**：剖面缩略图立刻按这个产品重画（半透明 60%），鼠标移开恢复；
  左栏那一行的 R 值和厚度也临时显示成这个产品，灰色斜体
- **点击某一行 = 选定**（动画见第二节），然后自动退出选产品状态

### 退出

`Done` 按钮、`Esc`、再次点击左栏那一行、点击右栏外任意位置 —— 都退出，不改变选择。

## 二、动画

整套动画的原则：**每一个动作都在说"东西从哪里来、到哪里去"**，不是为了动而动。
统一缓动 `cubic-bezier(.2, .8, .2, 1)`。

### 1. 进入（总长约 520ms）

| 时间 | 发生什么 |
|---|---|
| 0 – 80ms | 左栏被点的那一行轻微下压（`scale(.98)`），边框亮成 `--brand` |
| 0 – 360ms | **一道光束**：从左栏那一行的右边缘，画一条 `--brand` 色的 SVG 曲线连到右栏产品表的标题。用 `stroke-dashoffset` 从 0 画到满，线上带一个发光的点沿线跑过去（`filter: drop-shadow(0 0 6px var(--brand))`）。到达后 200ms 淡出 |
| 80 – 400ms | 剖面图面板用 **FLIP** 从 360px 收成 120px（记录起止位置，用 `transform` 做，不要直接动画 `height`） |
| 120 – 440ms | 产品表面板用 FLIP 上移到缩略图下面，同时拉高 |
| 300ms 起 | 表里各行依次入场：每行 `opacity 0→1`、`translateY(8px)→0`，间隔 25ms，最多前 12 行做，后面的直接出现 |

### 2. 选定一个产品（约 600ms）

| 时间 | 发生什么 |
|---|---|
| 0 – 150ms | 被点的那一行闪一下：背景 `--brand` 12% → 0，左边线变实 |
| 0 – 450ms | **数值飞过去**：克隆这一行的 `R2.6 · 110 mm` 文字，沿一条弧线从右栏飞到左栏那一层的数值位置（FLIP + 弧线用 `offset-path` 或两段 transform），落地时缩放 `1.15 → 1` |
| 350 – 750ms | 剖面缩略图重画，**新的保温层从下往上"长"出来**：给那一层的 `data-layer` 组加 `clip-path: inset(100% 0 0 0) → inset(0)`，400ms。环形符号正好像棉被铺开 |
| 450ms | 左栏那一行的 R 值和厚度数字做一次 count 动画（旧值滚到新值，200ms） |
| 600ms 起 | 自动退出选产品状态（进入动画倒放，300ms，不要光束） |

表盘的 R 值等计算结果有了之后，同样用数字滚动过去，不要跳变。

### 3. 退出（不选东西）

进入动画倒放，缩短到 300ms，不画光束。

### 4. 减少动态

`@media (prefers-reduced-motion: reduce)` 下：没有光束、没有飞行、没有逐行入场，
面板直接切换，只保留 150ms 的淡入淡出。

## 五、不要做的事

1. 不要让剖面图在选产品时消失，缩成一条但一直在
2. 不要用 `height` 做面板动画，用 FLIP 的 `transform`，否则会卡
3. 不要禁选"会被压扁"的产品，只提示
4. 动画不要超过 800ms，选完就回到正常状态
