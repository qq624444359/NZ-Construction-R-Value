## 一、问题：R6.60 不是这个部位的目标

表盘现在是一条带两个刻度的区间：

```
├──────────────●───────────────┤
R2.60                      R6.60
minimum                 reference
```

**R6.60 在 H1/AS1 第 6 版里不是对屋顶的要求。** 它只出现在两个地方：

| 出处 | 它是什么 |
|---|---|
| **Table 2.1.2.7** | 参考建筑热损失方程里的**除数**：`(Aroof + Askylight) ÷ 6.6`。它是整栋楼预算的一部分 |
| **Table 2.1.2.12** | **加热天花**的最低构造 R 值，六个气候区都是 R6.6 |

带 per-element 最低 R 值的 schedule method **已经从第 6 版删除**。所以对一个普通
（非加热）屋顶，第 6 版里唯一的硬下限是 **2.1.2.11 的 R2.60**。

**这不只是标签写错。** 画成区间会让人以为这个部位应该落进 R2.60–R6.60 之间，而
calculation method 的比较是**整栋楼的总量**：一个屋顶完全可以远低于 6.6 而整栋楼
轻松合规，也可以高于 6.6 而整栋楼不合规。拿单个部位去和参考建筑的除数比，是这个
方法不做的比较。

## 二、改成：一个阈值，不是一个区间

去掉区间和 `reference` 刻度。表盘上**只留一个阈值**——适用于当前部位的那条硬下限：

```
CONSTRUCTION R-VALUE

        —
      m²·K/W

  ──────────┃────────────────────
            R2.60
            minimum · 2.1.2.11

  Framing fraction 5.0% · isothermal planes per NZS 4214
```

- 阈值标记是一条**竖线**，不是区间端点；线的右侧不封口，因为**上不封顶**
- 标记下方两行：数值 + `minimum · <条款号>`
- 算出的 R 值**低于**阈值 → 数值和标记转 `--fail`
- **高于**阈值 → 数值用 `--text`（中性），标记用 `--pass`。**不要染成绿色的"好"**——
  过了硬下限只说明这个部位不违法，不说明整栋楼合规

### 各部位的阈值

| 部位 | 阈值 | 条款 |
|---|---|---|
| Roof / ceiling（非加热） | R2.60 | 2.1.2.11 |
| Roof / ceiling（**加热天花**） | **R6.60** | Table 2.1.2.12 |
| Wall（非加热） | R1.00 | 2.1.2.11 |
| Wall（加热） | R2.90 | Table 2.1.2.12 |
| Suspended floor（非加热） | R1.30 | 2.1.2.11 |
| Suspended floor / Slab（加热） | R2.50（zone 1–3）· R2.80（zone 4）· R3.00（zone 5–6） | Table 2.1.2.12 |
| Slab on ground（非加热） | **没有阈值** | — |

Slab on ground 非加热时：**不画任何标记**，标记位置写
`No Paragraph 2.1.2.11 minimum for this element`。（v3 的部位卡片已经这么写了，表盘
要跟卡片一致。）

**加热开关一打开，阈值当场换成 Table 2.1.2.12 那一档**，并且条款号跟着变——这正是
R6.6 在第 6 版里唯一合法的位置。

## 三、第二个标记只在有整栋楼数据时出现，而且它是真的目标

单看一个部位，除了硬下限之外没有任何"应该达到多少"可言——那个问题要整栋楼才能回答。

有项目上下文时（第四轮的 Headroom），在表盘上加**第二个标记**，用 `lowest_r`：

```
  ──────────┃──────────────┃─────
            R2.60          R3.07
            minimum        needed here
            2.1.2.11       given the rest of the building
```

- 这个标记会**随着别的部位变动而移动**，因为它是算出来的，不是查表来的
- 算出的 R 值低于它 → `--fail`，文案 `must reach R3.07`
- 高于它 → `--pass`，文案 `R0.53 of headroom`
- `binding` 不是 `heat loss` 时（被 2.1.2.11 或 Table 2.1.2.12 卡住），**两个标记重合**，
  这时只画一个，标 `minimum · <条款号>`，不要画成两个叠在一起

没有项目上下文时就只有硬下限那一个标记，**不要为了让表盘好看而补一个假的第二标记**。

## 五、不要做的事

1. **不要再把 R6.60 标成 reference 或画成区间端点。** 普通屋顶没有这个要求
2. 不要把区间画成"应该落在中间"的样子——上不封顶

5. 没有整栋楼数据时不要画第二个标记
